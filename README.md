A structured FAQ chatbot for an e-commerce store, powered by an LLM (Groq), with three Google Sheets acting as its knowledge base. When a customer sends a message via Telegram, the agent classifies the intent, queries the relevant sheet (policies, product knowledge, or operations/contact), and returns a concise, factual reply. It also has optional pathways to store conversation logs in Supabase, escalate via Gmail, or retrieve data from Google Cloud — though those are currently deactivated in your workflow.
